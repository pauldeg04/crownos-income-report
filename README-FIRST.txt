CROWNOS — CONSOLIDATED LATEST VERSION

INSTALLATION
1. Back up your current CrownOS folder.
2. Extract this ZIP.
3. Copy ALL files into your CrownOS project folder.
4. Choose REPLACE for duplicate filenames.
5. Keep the exact filenames. Do not add (1), (2), or (3).
6. Open login.html.

IMPORTANT
CrownOS still stores data in browser localStorage.
The project files may be in Google Drive, but browser data does not
automatically synchronize between computers. Export backups regularly
through Data Protection.

DASHBOARD FIX
The old hard-coded sidebar was removed from home.html.

BRANCH SAFETY
Renaming a branch migrates related sales, expenses, schedules,
therapist assignments, user assignments and client branch references.
